"Manus-ээс бүрэн салгасан" section) and reference infrastructure that no
longer exists: the old Manus OAuth login flow, the `sugi-mongo-detasex2.manus.space`

this folder as describing the current state of the project.** The current,
actively-maintained docs are in the repo root: `CLAUDE.md`, `ROADMAP.md`,
`PREMIUM-FEATURES.md`, `ADMIN-PANEL.md`, `SECURITY.md`, `UX-RESEARCH.md`,
