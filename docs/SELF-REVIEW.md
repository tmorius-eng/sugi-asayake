# Ажил дуусгахын өмнөх өөрийн шалгалт

Session бүр **commit хийхээсээ өмнө** энэ жагсаалтыг дуустал нь гүйцэтгэнэ.
Богино байлгасан нь санаатай: урт checklist уншигддаггүй.

## 1. Бодитоор ажиллаж байгааг баталсан уу

- [ ] Layout, CSS өөрчилсөн бол **зураг авч харсан** (код уншаад "болсон" гэж
      шийдэхгүй — давхцал, overflow, padding-ийг нүдээр).
- [ ] Шинэ tRPC procedure бол **бодит DB дээр** нэг удаа дуудаж үзсэн (тест
      эсвэл throwaway script).
- [ ] Хадгалаад **буцаж ачаалахад утга үлдэж байгаа** эсэхийг шалгасан
      (2026-09-14-ний барааны фактын bug яг үүнээс гарсан).
- [ ] Утсан дээр (390px) хэвтээ overflow 0.

## 2. Кодын чанар

- [ ] `pnpm check` цэвэр.
- [ ] `pnpm lint` цэвэр.
- [ ] Хамаарах тестүүд ногоон (бүрэн suite зөвхөн deploy-ийн өмнө).
- [ ] Шинэ логикт тест нэмсэн — ялангуяа **буруу байвал мөнгө/нөөцөд нөлөөлөх**
      зам бол заавал.
- [ ] Үлдэгдэл код алга: ашиглагдахгүй файл, түр script, `console.log`,
      `scripts/tmp-*.ts`.

## 3. Дүрэм зөрчөөгүй эсэх

- [ ] [PROJECT-GUIDE.md](PROJECT-GUIDE.md)-ийн "Хэзээ ч зөрчиж болохгүй дүрмүүд"-ийг
      шинэ код зөрчөөгүй (`sql.raw`, `branch_stock`, role builder, inline script,
      `partialForUpdate`, тестийн бодит мөр).
- [ ] Шинэ хуудас/талбар бол **admin-аас засагдана** уу? Hardcode текст үлдээгүй.
- [ ] Шинэ storefront текст гурван хэлний толь бичигт орсон уу.
- [ ] Хувийн мэдээлэл (нэр, утас, CV) зөвхөн зохих эрхэд харагдана уу.
- [ ] AI attribution хаана ч бичигдээгүй.

## 4. Баримтжуулалт

- [ ] [HISTORY.md](../HISTORY.md)-д **нэг догол** нэмсэн: юу, яагаад, ямар
      migration, юу шалгасан.
- [ ] Шинэ дүрэм гарсан бол PROJECT-GUIDE.md-д **1-2 мөрөөр** (түүх биш, дүрэм).
- [ ] Migration ажиллуулсан бол HISTORY.md-д дугаарыг нь бичсэн.
- [ ] Tom-ын хийх зүйл гарсан бол "Tom-оос хүлээж буй" жагсаалтад нэмсэн.

## 5. Дуусгах

- [ ] Commit хийж, push хийсэн (хийж дуусаагүй ажлыг session хооронд орхихгүй).
- [ ] Deploy хийсэн бол `/health` 200, өөрчилсөн хуудсаа амьдаар нэг удаа нээж
      харсан.
- [ ] Хариултдаа: юу хийсэн, юу шалгасан, юу ДУУСААГҮЙ — гурвуулаа бичсэн.
