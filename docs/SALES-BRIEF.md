# SUGI ASAYAKE онлайн дэлгүүр — танилцуулга (худалдан авагч байгууллагад)

_2026-09-20-ны байдлаар. Бүх тоо бодит систем дээр хэмжсэн._

## Юу вэ

Улаанбаатар дахь SUGI ASAYAKE (SUGI Drug Store Japan-ийн охин компани) брэндийн **бүрэн ажиллагаатай e-commerce систем**: худалдан авагчийн сайт + дэлгүүрийн удирдлагын самбар + нөөцийн бүртгэл + утасны мэдэгдэл. Эх код бүхэлдээ өөрийн өмч (Manus платформоос бүрэн салсан), нэг репозиторид, өөрийн серверт.

## Худалдан авагчид юу харагдах вэ

- Каталог (FULLTEXT хайлт, ангилал/арьсны төрөл/үнийн шүүлт, brand хуудас), барааны хуудас (variant, галерей, сэтгэгдэл + Like/Reply, **Асуулт-хариулт**, холбоотой бараа, **share** — Facebook/Messenger-д барааны зурагтай гарна)
- Сагс, зочны checkout (бүртгэлгүй), салбараас авах / хүргэлт, хямдралын код, гишүүнчлэлийн шатлан хөнгөлөлт, дэлгүүрийн зээл, **бэлгийн карт** (сайтаар зарагдана — төлбөр ормогц код автоматаар push/имэйлээр)
- Профайл: захиалгын түүх + PDF баримт, хаягийн дэвтэр, арьс/үсний профайл → **хувийн санал болголт**, хүслийн жагсаалт, push мэдэгдэл, Facebook-оор нэвтрэх, бүртгэл устгах (хуулийн шаардлага)
- PWA (утсанд суулгаж болно), харанхуй горим, cookie зөвшөөрөл, /help (холбоо барих, салбарууд, FAQ)
- Төлбөр: бэлэн; **QPay, StorePay код бэлэн** (merchant гэрээ ормогц асаана)
- Хуурамч захиалгаас хамгаалалт: зочин захиалгаа батлахын өмнө утсаа SMS-ээр баталгаажуулна; сэтгэгдэл автоматаар хүсэгдэж, урамшуулалтай; буцаалтын хүсэлт профайлаас; Messenger чат товч
- Хэмжилт: Google Analytics 4 + Meta Pixel (күкийн зөвшөөрлийн дараа), баркодоор Google-д олдох барааны хуудас, найрлага/хэмжээ/гарал үүслийн талбарууд

## Дэлгүүрийн ажилтанд юу байгаа вэ (/admin)

- **25 хэсэг**, 5 эрхийн түвшин (admin/finance/marketing/warehouse/staff), **царай танилтын хаалга** + idle lock
- Захиалгын урсгал (хүлээгдэж → баталгаажсан → бэлтгэсэн → хүргэлтэд → дууссан; цуцлал/буцаан олголт нөөц+зээлтэйгээ атомик); утас/Messenger-ийн захиалгыг гараар бүртгэх, захиалга засах, бэлтгэх хуудас/баримт PDF
- Нөөц: салбар/агуулах тус бүр, USB сканнераар хүлээн авах/тооллого, blind шилжүүлэг, бага нөөцийн alert, **бүх хөдөлгөөн ledger-т** (drift 0 гэдгийг самбар өөрөө шалгадаг); Smart Software (Smart POS) синк бэлэн
- Аналитик/CRM самбар: борлуулалт, маржин, сагс орхилт, хөрвүүлэлт, CAC, буцаалтын хувь, дүүрэг, Excel/PDF
- Контент бүхэлдээ засварлагдана: нүүрний зураг/текст, брэнд, урамшуулал, хуулийн баримт (3 хэлээр), SEO, cookie текст, имэйл/push загварууд
- Утасны push (ntfy): шинэ захиалга, төлбөр, цуцлал, нөөц бага, шилжүүлгийн зөрүү, сайт унасан

## Дэд бүтэц, аюулгүй байдал

- Oracle Cloud Токио: VM (pm2, systemd) + MySQL HeatWave (TLS, CA pinned, тусдаа `sugi_app` бага эрхтэй хэрэглэгч); Cloudflare (WAF, rate limit, bot fight, tunnel — сервер IP ил гарахгүй); зураг Cloudflare R2
- Backup: HeatWave 7 хоногийн автомат + **өдөр бүр шифрлэсэн dump тусдаа хаалттай bucket-д, 30 хоног** (restore шалгасан) + лаптопын нэмэлт хуулбар
- Uptime: GitHub-аас 10 мин тутам шалгаж унавал утсанд push; Honeybadger алдааны мэдээлэл
- Кодын хамгаалалт: bind parameter (SQL injection боломжгүй — sqlmap payload тест), CSRF, CSP nonce, secure cookie, rate limit (DB дээр), сканнер бот блок, moderation (5 хэлний хараалын шүүлт + ONNX загвар), NSFW зураг шүүлт, идемпотент захиалга (давхар товшилт давхар захиалга үүсгэхгүй)
- Deploy нэг команд (`scripts/oci/deploy.ps1`), ~3 минут, health шалгалттай; тусдаа **staging** орчин (өөрийн DB хуулбар); CI дээр бодит MySQL-тэй integration тест
