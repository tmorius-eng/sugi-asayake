# SUGI ASAYAKE — Ажилтны гарын авлага (/admin)

Энэ бол дэлгүүрийн ажилтанд зориулсан **өдөр тутмын** заавар. Программчилсан тайлбар биш — юу дарж, юу хийхийг л бичсэн. Хаяг: `https://sugi.karkaron.com/admin` (домэйн солигдвол ижил зам).

---

## 1. Нэвтрэх

1. `/admin` руу орно → утасны дугаар + нууц үг.
2. **Царай таних** — камер асаж, толгойгоо цагирагийн дагуу эргүүлнэ (анх удаа бүртгүүлнэ, дараа нь 3 секунд).
3. 25 минут юу ч хийхгүй бол дахин царай асууна; 8 цагийн дараа заавал дахин нэвтэрнэ.

⚠️ Утсан дээр зөвхөн **https** хаягаар (камер http дээр ажиллахгүй). Камер нээгдэхгүй бол хөтчийн зөвшөөрлөө шалга.

**Эрхийн түвшин** (хэн юу хардаг): `staff` — Хянах самбар, Шинэ мэдээ, Хуанли · `warehouse` — Бүтээгдэхүүн, Захиалга, Дэлгүүрийн худалдаа, Бараа хүлээн авах · `finance` — Аналитик, Захиалга (буцаан олголт), Бэлгийн карт · `marketing` — контент/зураг/брэнд/урамшуулал/тохиргоо · `admin` — бүгд.

## 2. Захиалга ирэхэд (өдрийн гол ажил)

Шинэ онлайн захиалга орох бүрт утсанд **push** ирнэ ("Шинэ онлайн захиалга"), admin-ийн дээд хонх дээр ч гарна.

1. **Захиалга** хэсэг → шинэ мөр "Хүлээгдэж байна".
2. Мөрийг нээж харна: бараа, тоо, хүргэлт (Улаанбаатар хүргэлт / салбараас авах), төлбөр (бэлэн / QPay).
3. Утсаар/мессежээр баталгаажуулаад → **Баталгаажсан**.
4. Бараагаа бэлдээд → **Бэлтгэсэн**. Хүргэлтэд гарахад → **Хүргэлтэд гарсан** (хүргэлтийн дугаар байвал бичнэ).
5. Хүргэгдсэн/авсан → **Дууссан**. Бэлнээр төлсөн бол энэ үед төлбөр "төлөгдсөн" болно.

Төлөв солих бүрт харилцагчид push (утсанд) + имэйл (байвал) автоматаар очно.

**Цуцлах**: харилцагч хүсвэл эсвэл нөөц байхгүй бол → **Цуцалсан**. Нөөц автоматаар буцна. Төлбөр төлсөн захиалгыг цуцалсан бол мөрөнд "Буцаан олголт хүлээгдэж буй" гэж гарна → finance **Буцаан олгох** дарна (дэлгүүрийн зээл ч буцна).

**Туршилтын захиалга** (нэр "ТУРШИЛТ …") — шууд цуцална.

**Гараар захиалга бүртгэх** (утсаар/Messenger-ээр ирсэн): Захиалга → **"Гараар захиалга"** → нэр, утас, суваг, хүргэлт/салбар, төлбөр, бараагаа нэр/баркодоор хайж нэмээд "Захиалга үүсгэх". Нөөц үндсэн салбараас хасагдана, харилцагчид имэйл/SMS (асаалттай бол) очно.

**Захиалга засах**: мөрийн **"Засах"** товч — нэр, утас, хаяг, хүргэлтийн арга хаагдаагүй бүх захиалгад; барааны мөр (тоо нэмэх/хасах, бараа солих) зөвхөн **төлбөр төлөгдөөгүй** үед. Төлсөн захиалгын бараа өөрчлөх бол буцаан олголт хийгээд шинэ захиалга үүсгэнэ.

**Хэвлэх**: **"Бэлтгэх хуудас"** (агуулахад — үнэгүй, ☐ + баркод + тоо), **"Баримт PDF"** (харилцагчид).

**Буцаалтын хүсэлт**: харилцагч профайлаасаа дууссан захиалгад 14 хоногийн дотор "Буцаах хүсэлт" илгээвэл push ирж, мөрөнд шар тэмдэглэл + шалтгаан гарна. Барааг хүлээн аваад шалгасны дараа → **Буцаагдсан** → буцаан олголт.

**Бэлгийн карттай захиалга**: "Бэлгийн карт 50 000₮" гэх мөртэй захиалга хүргэлтгүй, салбаргүй байж болно (цахим). Төлбөрийг (бэлэн/шилжүүлэг) авмагц захиалгыг шууд **Дууссан** болго — тэр мөчид картын код автоматаар үүсч, худалдан авагчид push/имэйлээр очиж, профайл дээр нь харагдана. QPay-ээр төлсөн бол код төлбөр ормогц өөрөө гарна. Цуцалбал ашиглагдаагүй код хүчингүй болно. Кодуудыг Урамшуулал → Бэлгийн карт жагсаалтаас ("Захиалга N" тэмдэглэлтэй) харж болно.

## 3. Бараа

- **Бүтээгдэхүүн** → "Шинэ бараа": нэр, ангилал, брэнд, үнэ, **хуучин үнэ** (хямдрал харуулах бол), SKU = баркод, зураг, нөөц, нийтлэх.
- Зураг: Content & Media биш, барааны өөрийн "Зураг" талбар. Цагаан дэвсгэртэй packshot хамгийн сайн.
- Нөөц **гараар бүү зас** — Бараа хүлээн авах → Тооллого / Хүлээн авах-аар (доор). Гараар засвал "нөөцийн хөдөлгөөний бүртгэл"-д зөрүү гарна.
- Ангилал: Бүтээгдэхүүн → "Шинэ ангилал үүсгэх" (зурагтай). Бараагүй ангилал сайтад гарахгүй.

## 4. Бараа хүлээн авах, тооллого, шилжүүлэг (агуулах/дэлгүүр)

- **Хүлээн авах**: USB сканнераар баркод уншуулна → тоо → "Батлах". Бүртгэлгүй баркод бол эхлээд бараа үүсгэнэ.
- **Тооллого**: салбар сонгож бүх барааг сканнердана → "Батлах" → нөөц бодит тоо болно. ("Эхний үлдэгдэл" — агуулах руу шилжих өдөр.)
- **Шилжүүлэг**: агуулах "Илгээх" (агуулахаас хасагдана) → дэлгүүр **тоог харахгүй** сканнердаж "Хүлээн авах" → зөрүү бол admin-д push, admin шийднэ.
- **Дэлгүүрийн худалдаа (POS)**: салбар дээр биечлэн зарсныг бүртгэнэ — нөөц хасагдана.

## 5. Сэтгэгдэл, Асуулт

- Захиалга дууссанаас 3 хоногийн дараа систем худалдан авагчаас сэтгэгдэл **автоматаар хүснэ** (push + имэйл, нэг удаа). Дэлгүүрийн тохиргоо → "Захиалга" → "Сэтгэгдлийн урамшуулал" дээр дүн (жишээ 2000₮) тавибал сэтгэгдэл бичсэн хүнд дэлгүүрийн зээл автоматаар нэмэгдэнэ.

- **Сэтгэгдэл** хэсэг: доромжлол автоматаар хаагддаг; илүү бол "Нуух"/"Устгах". Хариулт бичиж болно (ажилтны тэмдэгтэй гарна).
- Хуудасны доод хагас — барааны **асуултууд**: хариулна, эсвэл нуухаа шийднэ. Хариулсан асуулт сайт дээр бүх хүнд харагдана.

## 6. Контент (marketing)

- **Content & Media**: нүүрний зургууд (hero 6 хүртэл слайд, ангилал, "яагаад бид" картууд). "BRAND DEFAULT" = зураг оруулаагүй.
- **Content & Media → текст**: нүүрний бүх гарчиг/тайлбар. Монголоор бичсэн текст англи/япон руу автоматаар орчуулагдахгүй — толь бичигт байгаа анхдагч үгийг л орчуулдаг.
- **Баримт бичиг**: Хувийн нууцлал / Үйлчилгээний нөхцөл / Буцаалт — **хэл бүр тусдаа** (Монгол / English / 日本語 товч). Монголоо засаад бусад хэлээ мартаж болохгүй.
- **Шинэ мэдээ**: WordPress шиг редактор; "Нийтлэх" дарахгүй бол сайтад гарахгүй.
- **Брэндүүд**: нүүрний "Топ брэнд" — зураг + лого (тунгалаг PNG).
- **Урамшуулал / Хямдралын код / Бэлгийн карт**: код үүсгэхэд "нэг хэрэглэгч хэдэн удаа" гэдгийг заавал тавь (1 гэвэл нэг л удаа). Бэлгийн карт гараар олгох (бэлэг, гомдол засах) энд; сайтаар зарагдах картууд нь "Бэлгийн карт" ангиллын бараа — шинэ дүн нэмэх бол Бүтээгдэхүүн → Шинэ бараа, **Төрөл = Бэлгийн карт**, үнэ = картын дүн.

## 7. Тохиргоо (marketing/admin)

- **Дэлгүүрийн тохиргоо**: утас, имэйл, ажлын цаг, Facebook/Instagram, хүргэлтийн төлбөр, имэйл/push/SMS мэдэгдлийн текстүүд, **SEO баталгаажуулах кодууд** (Google Search Console, Meta), **Google Analytics 4 / Meta Pixel ID** (зочин күки зөвшөөрсний дараа л ажиллана), "Захиалга" бүлэг: зочны утас баталгаажуулалт (1/0), захиалгын SMS (1/0), сэтгэгдлийн урамшуулал, буцаалтын хугацаа.
- **Бараа → Найрлага / Хэмжээ / Гарал үүсэл / Хадгалах хугацаа**: барааны формын доод хэсэгт, эсвэл CSV импортоор (`ingredients`, `netContent`, `countryOfOrigin`, `shelfLifeMonths` баганууд). Бөглөсөн нь барааны хуудсанд хүснэгтээр гарна.
- **Салбарууд**: нэр, хаяг, утас, газрын зураг, "онлайн нөөцөд тооцох", "нөөц бага" босго.
- **Интеграцууд**: ntfy (утасны push — ажилтан гарвал сэдвийг "Шинэчлэх"), QPay, StorePay, Smart Software, Brevo. "Туршилт" товч утсанд шууд илгээнэ.
- **Утасны мэдэгдэл**: илгээсэн/алдаатай push-ийн жагсаалт.

## 8. Юу хийж болохгүй вэ

- Бодит DB дээр "туршиж үзье" гэж захиалга/бараа үүсгээд орхихгүй — үүсгэсэн бол цуцал/устга.
- Нууц үг, ntfy token, API түлхүүрийг chat/мессежээр бүү илгээ.
- Нөөцийг Бүтээгдэхүүн хэсгээс гараар бүү зас (§3).
- Хуулийн баримтыг засахдаа хуулийн утга хэвээр эсэхийг шалга; буруу бол "Анхны хувилбар руу буцаах".

## 9. Асуудал гарвал

- Сайт нээгдэхгүй → 10 минутын дотор admin утсанд "DOWN" push ирнэ (GitHub-ийн шалгалт). Эзэн/хөгжүүлэгчид мэдэгд.
- Захиалга ирсэн ч push ирэхгүй → Интеграцууд → ntfy → "Туршилт"; утсан дээрх ntfy апп сэдэвт бүртгэлтэй эсэхээ шалга.
- Царай таних гацвал → өөр хөтөч/утас; admin эрхтэй хүн Аюулгүй байдал хэсгээс бүртгэлийг дахин нээж өгнө.
- Нөөц зөрвөл → Хянах самбар → Системийн байдал → "Нөөцийн хөдөлгөөний бүртгэл" улаан бол хөгжүүлэгчид.
