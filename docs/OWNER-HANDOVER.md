## 3. ⛔ Сэргээх БОЛОМЖГҮЙ гурван нууц

Эдгээрийг алдвал **хэн ч**, ямар ч аргаар сэргээж чадахгүй. Хүлээлцэх өдөр
нууц үгийн менежерт (1Password, Bitwarden) хийж, хоёр хүн тусад нь хуулбартай
болох ёстой.

| Нууц | Алдвал |
|---|---|
| `INTEGRATIONS_ENCRYPTION_KEY` | /admin-д оруулсан **бүх** интеграцын нууц (ntfy token ба сэдвүүд, StorePay-ийн 7 утга, Smart Software) уншигдахгүй болж, бүгдийг дахин гараар оруулна. Мөн **ажилтан бүрийн царайны бүртгэл** уншигдахгүй болж (2026-09-22-оос шифрлэгдсэн), бүгд царайгаа дахин бүртгүүлнэ |
| `BACKUP_PASSPHRASE` | Cloudflare R2 дахь өдөр бүрийн шифрлэгдсэн нөөц хуулбар **бүгд үүрд нээгдэхгүй** |
| `JWT_SECRET` | Нэвтэрсэн бүх хэрэглэгч гарна (сэргээгдэх боловч бүгд дахин нэвтэрнэ) |

**Дөрөв дэх эгзэгтэй зүйл — SSH түлхүүр.** Deploy, өгөгдлийн санд хандах,
нөөцлөлт гурвуулаа `sugi-oci` нэртэй нэг ssh түлхүүрээр явдаг. Хоёр лаптоп
хоёулаа алдагдвал зөвхөн **Oracle консолын эрхээр** дамжин шинэ түлхүүр нэмж
болно — тиймээс Oracle дансны нэвтрэх эрх нь ssh түлхүүрээс ч чухал.

## 4. Домэйн солих шалгах хуудас

Хуучин эзний хувийн домэйн (`karkaron.com`) кодод **21 газар** бичигдсэн байсан.
2026-09-20-нд харилцагчид харагддаг газруудыг нь хөтчийн өөрийн хаягаас уншдаг
болгосон. Шинэ домэйн руу шилжихэд:

**Кодоос ГАДУУР (тохиргооноор):**
- `.env` → `PUBLIC_BASE_URL`
- /admin → Дэлгүүрийн тохиргоо → холбоо барих утга, SEO баталгаажуулах код
- Cloudflare → DNS, tunnel route, cache rules

**Кодод үлдсэн (хөгжүүлэгч засна):**
- `scripts/oci/deploy.ps1` — health шалгах хаяг
- `.github/workflows/uptime.yml` — мониторингийн хаяг
- `scripts/cloudflare-harden.mjs` — account/zone ID, host, эзний имэйл
- `scripts/load/storefront.js` — ачааллын тестийн хаяг
- `shared/store-settings.ts` — SMS загварын анхдагч утга

## 5. Брэнд солих (хэрэв шинэ нэрээр ажиллуулах бол)

**/admin-аас код өөрчлөхгүйгээр солигдоно (~70%):** дэлгүүрийн нэр, лого,
нүүрний бүх зураг/текст, холбоо барих утас/имэйл/цаг/сошиал, салбарууд,
хуулийн 3 баримт (3 хэлээр), имэйл/SMS/push загварууд, хүргэлтийн үнэ,
гишүүнчлэлийн зэрэглэл, GA4/Pixel ID.

**2026-09-20-нд кодоос тохиргоо руу гаргасан зүйлс:** захиалгын баримт PDF-ийн
толгой ба хөл, бэлгийн картын имэйл, Excel/PDF тайлангийн гарчиг, төлбөрийн
нэхэмжлэхийн тайлбар, утасны мэдэгдлийн туршилт, имэйлийн илгээгчийн нэр,
апп суулгах зааврын зураг (хөтчийн хаягаас), Google Merchant feed-ийн нэр
(энэ нь өмнө нь /admin-ийн өөрчлөлтийг үл тоодог **алдаатай** байсан).

**2026-10-05: Брэнд студи + эзэн солих (бүгд /admin-аас, код өөрчлөхгүй):**
- **/admin → Брэнд студи → Эзэн солих** таб — бүх алхам нэг дор: брэндийн нэр (бүтэн нэр,
  богино нэр, нийлүүлэгч, зохиогчийн эрх), лого, өнгө, холбоо барих, салбар, хуулийн баримт,
  интеграц, хэмжилт. Код дотор "SUGI ASAYAKE" хатуу бичигдээгүй (`brand-name-guard.test.ts`).
- **Өнгө ба хэлбэр**: логоноос 3 палитр автоматаар, AA (уншигдах) хамгаалалттай, амьд
  урьдчилан харалт; **Нүүрний бүтэц**: хэсгүүдийг дараалах/нуух; **Баярын загвар**: 13 баяр.
- **PWA (апп болгон суулгах) нэр, өнгө** тохиргооноос (`/manifest.webmanifest` серверээс).
  ⚠️ Хөтчийн таб/утасны дүрс (`client/public/icons/*.png`) болон PWA screenshot-ыг гараар солино.
- **Бэлгийн картын кодын угтвар** — Дэлгүүрийн тохиргоо → `gift-card-prefix` (хуучин кодууд хүчинтэй).
- **Брэнд багц** (`brand-pack.v1.json`) — өнгө, баяр, нүүрний бүтэц, текст, зургийн хаягийг
  татаж, өөр суулгац дээр импортлоно (нууц, хэрэглэгч, захиалга ороогүй).
- **Хуучин эзний өгөгдөл цэвэрлэх** — серверт хандах эрхтэй хүн (вэбээс товч ЗОРИУД байхгүй):
  ```
  pnpm exec tsx scripts/new-owner-reset.ts --keep-admin-phone=<шинэ эзний утас> --keep-catalog            # dry-run
  pnpm exec tsx scripts/new-owner-reset.ts --keep-admin-phone=<утас> --keep-catalog \
    --apply --i-have-a-backup --confirm="<одоогийн сайтын нэр>" --i-know-this-is-production
  ```
  Харилцагч, захиалга, сэтгэгдэл, лог, хуучин интеграцийн түлхүүр, царайн бүртгэл устна;
  зөвхөн заасан admin үлдэнэ. `--keep-content/--keep-branches/--keep-brand` сонголттой.
  Эхлээд `scripts/db-backup.ps1`-ээр нөөц ав. Шинэ эзний admin эхлээд сайтаар бүртгүүлж,
  `scripts/make-admin.ts`-ээр admin болсон байх ёстой.
- **Дэд бүтцийн параметр**: `deploy.ps1 -SshHost <host> -PublicHost <домэйн>`
  (эсвэл `DEPLOY_SSH_HOST`/`DEPLOY_PUBLIC_HOST`), `cloudflare-harden.mjs` нь
  `CLOUDFLARE_ACCOUNT_ID`/`CLOUDFLARE_ZONE_ID`/`SITE_HOST`/`OWNER_EMAIL`, uptime workflow нь repo
  variable `SITE_HOST`, Playwright-ийн staging нь `E2E_STAGING_HOST`.
- **Theme зураг R2-д** (`themes/holidays/v1/`) — шинэ bucket руу нүүхдээ R2 хуулбарлахад хамт очно.

**Кодоор л солигдох үлдэгдэл:** орчуулгын толь бичгийн монгол түлхүүрүүд (шинэ нэр орчуулгагүй
монголоор харагдана), хуулийн баримт ба site_text-ийн **анхны** (seed) текст дэх "SUGI Drug
Store Japan" — /admin-аас дарж бичнэ, хайлтын брэндийн alias seed.

⚠️ Энэ бол **нэг эзэнтэй** систем, олон дэлгүүрийн платформ биш. Схемд
"түрээслэгч" гэсэн ойлголт байхгүй.
